# Specs

This directory holds implementation specs for non-trivial work in Tome.

## Naming Convention

- `YYYY-MM-DD-short-title.md`
- Example: `2026-03-28-phase2-router-and-agents.md`

## When to Write a Spec

- New feature
- Multi-file refactor
- API contract change
- Storage/data model change
- Any task with significant trade-offs

## Recommended Template

```markdown
# <Title>

## Problem
## Scope
## Goals
## Non-goals
## Proposed Design
## API and Data Changes
## Risks and Mitigations
## Test Plan
## Rollout Plan
## Implementation Checklist
```
