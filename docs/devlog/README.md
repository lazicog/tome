# Development Log

This directory contains a chronological journal of development work on HelpMeLearn. Each entry captures what was built, decisions made, issues encountered, and what's next.

## When to Write an Entry

- Completing a feature or implementation phase
- Finishing a significant refactor
- Resolving a complex bug
- Any work session with meaningful progress

## Template

```markdown
# YYYY-MM-DD: Short Title

## What was done
- Bullet points of completed work

## Key decisions made
- Link to relevant ADRs (e.g., "See ADR-0001")

## Issues / Gotchas
- Problems encountered and how they were resolved
- Surprising behavior worth remembering

## Next steps
- What comes next based on this work
```
